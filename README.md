# Network Simulation Project

## Overview
This project contains a Cisco Packet Tracer network simulation saved as `421project_22101506.pkt`.

The Packet Tracer file can be opened in Cisco Packet Tracer to inspect the network topology, review device configurations, and test connectivity between network devices.

## Project File
- **File:** `421project_22101506.pkt`
- **Format:** Cisco Packet Tracer (`.pkt`)

## Requirements
- Cisco Packet Tracer installed on your computer
- A computer capable of running Cisco Packet Tracer

## How to Open
1. Download or clone this repository.
2. Open Cisco Packet Tracer.
3. Select **File → Open**.
4. Choose `421project_22101506.pkt`.
5. Review the topology and inspect the device configurations.

## How to Test
After opening the project:
1. Check that all required devices and connections are present.
2. Review IP addresses and other relevant configurations.
3. Use **Desktop → Command Prompt** on PCs to test connectivity with commands such as `ping <destination-IP>`.
4. Use Simulation Mode, if needed, to observe packet flow.
5. Save a copy before making changes.
